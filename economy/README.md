# Модель экономики

Скрипт, который «играет» за игрока и подбирает числа так, чтобы 8 уровней шли ~2,5 часа.

> **Это модель, а не реальные игроки.** Главное допущение — «обычный» игрок кликает 4 раза в секунду
> и всё время в игре. Весело ли это — модель сказать не может, это только плейтест.

## Запуск

```bash
python3 economy/model.py              # подбирает числа, пишет отчёт и конфиг (~20 секунд)
pip install lupa                      # один раз, нужно только для теста
python3 economy/test_lua_parity.py    # проверяет, что Lua-конфиг считает так же, как модель
```

Нужен только Python 3.9+, других зависимостей у модели нет.

## Что получается

| Файл | Что это |
|---|---|
| `output/report.md` | Отчёт: время уровней у разных игроков, все числа, таблицы магазина |
| `output/EconomyConfig.lua` | ModuleScript для Roblox: числа + формулы (скорость колышка, цены, слои, ветер) |

`EconomyConfig.lua` не правьте руками — меняйте модель и запускайте заново.

## Как устроена игра в модели

- **Удар:** сила инструмента × клики в секунду. **Помощники** бьют сами. **Сила** умножает и то и другое.
- **Монеты:** 1 единица силы = 1 монета. Твёрдый слой замедляет колышек, но не доход.
- **Колышек:** мм в секунду = сила × (1 − замедление ветра) / (твёрдость уровня × множитель слоя).
- **Слои:** трава → земля → глина → камни → корни → скала, каждый твёрже.
- **Ветер:** 3 стадии гасят 15/30/45% удара. Каждые 75 с порыв на 6 с — колышек ползёт назад,
  но не выше последней вехи.
- **Пик урагана:** на дне 60 секунд против абсолютной силы урагана. Нужно ≥ 90% его силы,
  иначе колышек вырвет — добиваешь 3% и пробуешь снова.
- **Вехи:** примерно каждые 25 с, сундук = 10 с дохода. **Подарок** за время в игре: раз в 10 минут.
- **Кооп:** все бьют один колышек; грунт и ураган для пати × (1 + 0.75 × (игроков − 1)).

## Главные ручки (в начале `model.py`)

| Ручка | Что меняет |
|---|---|
| `TARGET_MIN` | Сколько минут должен длиться каждый уровень |
| `LEVELS` | Объекты, колышки, глубина |
| `PEAK_K` | **Самая чувствительная.** Сила пика урагана относительно силы эталона. 1.0 → 2:36 на игру, 1.15 → 4:00 |
| `HELPER_DPS_BASE` | Насколько сильны помощники = насколько важны клики |
| `LAYERS`, `WIND_STAGES` | Твёрдость слоёв и замедление ветра |
| `TOOL_*`, `HELPER_*`, `STR_*` | Цены и сила инструментов, помощников, Силы |
| `CHECKPOINT_EVERY_SEC`, `CHEST_SECONDS`, `GIFT_*` | Награды |

После любой правки: запустить модель → посмотреть `output/report.md` → запустить тест.

## Чего модель не знает

- Реальную скорость кликов игроков в Roblox.
- Ритм-комбо, ивенты кроме порывов, донат, бусты.
- AFK, выходы из игры и возвращения.
- Интересно ли играть.
